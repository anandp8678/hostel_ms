Import Room Allocations

Back to allocations

Upload a CSV file containing students and their allocated rooms. You can use a minimal CSV (roll_no, room) or the combined CSV with all student & parent info. Download combined template.

Supported columns:

  • roll_no (required): Student roll number (e.g. CS2101)
  • room (required): Room code (e.g. A-101, B-102)
  • start_date (optional): Date of allocation (defaults to today)
  • name (optional): Student name (new students are registered automatically)
  • course, phone, parent_name, parent_phone (optional): All student & parent details are saved/updated

Note: If a student already has an active room, their previous room is vacated and the new room allocated. Room capacities are validated automatically.
