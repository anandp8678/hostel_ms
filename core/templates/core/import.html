Import Students & Room Allocations

Back to students

Upload one combined CSV file containing student details, parent details, and room allocations. Download combined template.

Supported columns (all in one CSV):

  • name (required for new students): Student's full name
  • roll_no (required): Student roll number / login username
  • course (optional): Course / branch / department
  • phone (optional): Student contact number
  • parent_name (optional): Parent or guardian full name
  • parent_phone (optional): Parent phone number (used for parent login: p + phone)
  • room (optional): Allocated room (e.g. A-101). Assigned automatically upon upload
  • start_date (optional): Room allocation start date (defaults to today)

Combined Processing: Works for both new and existing students. If a student is already registered, their profile and parent info are updated, and they are automatically allocated to the specified room.
